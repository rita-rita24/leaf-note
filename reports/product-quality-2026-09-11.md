# LeafNote 製品品質の改善記録

確認日: 2026-09-11。対象は既存の単体 HTML アプリと配布ページ。

## 今回の改善

| 利用者が困る場面 | 改善した動作 |
| --- | --- |
| 別タブを閉じると最新のノートが古い内容に戻る | 無操作タブの終了時書き込みを抑止し、保存内容の競合を検出したタブは自動保存を停止。編集内容を維持し、HTML への退避方法を通知する。 |
| Undo／Redo 後の再読み込みで以前の内容が復活する | 履歴操作でも保存 revision を前進させ、実際の保存完了までは未保存として扱う。エクスポート時の revision も正規化後に引き継ぐ。 |
| 別の HTML 文書を開いたのに、ブラウザ内の別文書が表示される | 文書を識別し、異なる文書の新しい日時だけでは埋め込み内容を置き換えない。 |
| 配布ページから使い始められない | HTML の直接ダウンロード、ブラウザで開くリンク、初回手順とバックアップの説明を追加。リポジトリリンクを修正。 |
| タッチ操作で取り込みやヘルプへ行けない | Markdown 取り込みとヘルプをサイドバーに追加。検索・ゴミ箱・ヘルプに閉じるボタンを設けた。 |
| 設定を変えるとキーボード操作の位置が失われる | 再描画後のフォーカスとスクロール位置を維持し、モーダル背後への操作を抑止。閉じたサイドバーも操作対象から外す。 |
| 中間の画面幅で配布ページが横にはみ出す | コンテンツ幅を修正し、320／768／1280px のダウンロード導線を回帰テストで確認する。 |
| 本体を修正したのに配布ページだけ古い | `npm run build` で同期。`npm test` の前に本体と配布ソースの完全一致を検査する。 |

- 既存の一時 Chrome プロファイルによるテストランナーを利用し、普段のブラウザデータには書き込まない。
- ベースラインの既存テスト 131 件が通過。
- 最終 `npm test` は **144 件すべて成功**（追加 13 件、終了コード 0）。配布チェック、テストランナーの構文チェック、`git diff --check` も成功。[実行ログ](./product-quality-test-run.log)。
- 配布同期スクリプトは隔離した fixture 26 ケースで同期・差分保持・破損検出を確認。

```sh
npm run build
npm test
```

詳しい前提と個別コマンドは [TESTING.md](../TESTING.md) を参照。

## リリース判断に残る確認

この記録は有料販売の準備完了を保証するものではない。次の点は、今回の自動テストと区別して扱う。

- Safari／Firefox、iOS／Android 実機での編集・日本語 IME・添付・ダウンロード。Chrome の画面幅変更は別ブラウザや実機の確認を代替しない。
- 実際の画面の目視確認とスクリーンリーダー操作。今回、操作用ブラウザのローカルファイル URL 制限により画面プレビューは未実施。
- 日常利用に近い大量ノートでの長時間利用、OS 終了・ブラウザ強制終了・ストレージ容量不足からの復旧。
- 対象利用者が説明なしで「開始・取り込み・バックアップ・復元」を完了できるかの利用確認。

自動保存はブラウザ内の保存で、元の HTML への書き戻しや端末間同期ではない。変更の自動統合と文書ごとの独立した保存領域は今回の対応に含めず、競合時は編集を残して HTML へ退避する動作とした。
