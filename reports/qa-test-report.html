4. 見つけたバグ

優先度バグ原因影響状態
P1IME composition 中の Enter/Escape が一部で通常キー扱いになる。isComposing のみ見ており、macOS/Chrome IME の keyCode/which 229 や document capture Escape を考慮していなかった。日本語変換中に block 分割、title blur、dialog/search close が起きる可能性。修正済み
P1selector-breaking block id で選択/focus/table 操作が壊れる。保存済み block id を CSS selector 文字列へ直接補間。tampered/localStorage state で DOMException または別要素選択。修正済み
P0Maskinger が自分で生成した MASK_SECRET_0001 を再マスクする。Authorization/Bearer の後続 regex が placeholder を secret token として再処理。対応表に placeholder 自体が original として入り、復元が連鎖的に壊れる。修正済み
P0URL 内 token が先にマスクされ、URL 対応表 original に placeholder が混入する。key/value secret 検出が URL 検出より先に走っていた。復元後の URL に MASK_SECRET_* が残る。修正済み
P0旧 sessionStorage 対応表の入れ子 placeholder を復元しきれない。復元が単一パスで、旧バグ由来の MASK_URL_0001 → URL 内 MASK_SECRET_0001 を再解決しなかった。復元後テキストに placeholder が残り、ユーザーが秘匿値を完全復元できない。修正済み
P016桁カード番号が 12桁 ID として先に部分マスクされる。12桁 PII_ID regex が Luhn カード検出より先に実行されていた。カード番号末尾 4 桁が平文で残る。修正済み
P1MAC アドレスが IPv6 として分類される。IPv6 regex が MAC regex より先に実行されていた。mask はされるが、対応表の種類が誤り監査や復元確認が紛らわしい。修正済み
P1HTML export が private/local network の remote image URL を fetch できる。remote image inline 化で http/https の raster-looking URL を fetch 前に network 範囲判定していなかった。untrusted note を export したユーザーのブラウザから loopback/private network へリクエストが出る。修正済み
P1dialog が重なると古い resolver が未解決で残る。dialogResolver が単一グローバルで、新しい dialog が既存 resolver を置き換えていた。先に開始した confirm/prompt が永久に settle せず、後続フローが止まる可能性。修正済み

overlapping dialog resolver新しい dialog を開く前に既存 dialog resolver を null で settle し、未解決 Promise を残さない。overlapping dialogs settle the replaced resolver before showing the next dialog成功
